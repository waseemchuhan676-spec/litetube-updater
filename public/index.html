Install on Android TV / Smart LED

  1. From the TV browser (easiest): open this page on the TV browser, tap Download APK, then open the downloaded file. When asked, allow “Install unknown apps” for the browser.
  2. From a USB stick: download the APK on your phone or PC, copy it to a USB stick, plug it into the TV, open it with the TV file manager, and install. If blocked, allow “Install unknown apps” for the file manager app first.
  3. From a PC with ADB: adb connect <tv-ip>:5555 then adb install app-release.apk

Install on Android mobile

  1. Tap Download APK above.
  2. Open the downloaded file and tap Install. If asked, allow “Install unknown apps” for your browser once.
