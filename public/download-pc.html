Get the full app on PC (emulator)

  1. Install an Android emulator on your PC (for example BlueStacks, available for Windows and Mac).
  2. Download the LittleTube APK with the button below (it starts working once the first v1.0.0 release is published).
  3. Open the APK inside the emulator to install it.
  4. Open LittleTube in the emulator and use it like on an Android device.

What you need: a PC that can run an Android emulator, plus the APK (version 1.0.0). How smoothly it runs depends on the emulator and your PC.

Frequently Asked Questions

Can I use LittleTube on my PC without installing anything?

Yes. Paste a YouTube link in the web player above and watch it in your browser — no install, no account.

Is there a LittleTube app for Windows or Mac?

No native Windows or Mac app exists. The web player above works in any browser, and the full Android app runs on a PC inside an Android emulator.

Can I download videos on PC?

Not from the web player. For downloads, install the Android app inside an emulator (steps above) — downloads then work like on Android.

Do I need an Android phone too?

No. The web player needs only a browser, and the emulator runs the APK on your PC by itself.
